# AI 구조요청 신호탐지 시스템

브라우저 마이크로 소리를 분석해 비명·도움 요청·두드림 같은 구조 신호를 감지하는 공주정보고등학교 소방안전과 수업용 웹앱입니다. 위험 신호가 설정한 확률을 넘으면 화면 경보와 사이렌이 작동하고 감지 기록이 쌓입니다.

설치나 빌드가 필요 없는 정적 웹앱입니다. 모델이 없어도 **Mock 모드**를 켜서 정상 감시 → 경보 → 기록 흐름을 시험할 수 있습니다.

## 1. Teachable Machine에서 소리 모델 만들기

1. [Teachable Machine 오디오 프로젝트](https://teachablemachine.withgoogle.com/train/audio)에 접속합니다.
2. `Background Noise` 클래스에 교실의 평상시 소음을 20초 이상 녹음합니다.
3. 클래스를 추가해 구조 신호를 각각 8개 이상 녹음합니다.
   - `비명·도움 요청`: “살려 주세요”, “여기 사람 있어요”, 비명 등
   - `두드림`: 문, 책상, 파이프를 일정하게 두드리는 소리
4. **모델 학습(Train Model)** 을 누르고 학습이 끝날 때까지 기다립니다.
5. **모델 내보내기(Export Model) → TensorFlow.js → 모델 업로드(Upload my model)** 를 선택합니다.
6. 발급된 `https://teachablemachine.withgoogle.com/models/…/` 주소를 복사합니다.

클래스 이름에 `비명`, `도움`, `구조`, `살려`, `두드`, `노크`가 들어가면 앱이 자동으로 경보 대상으로 선택합니다. 다른 이름을 사용했다면 모델 로딩 후 나타나는 체크박스에서 직접 지정하세요.

## 2. 모델 주소를 앱에 넣기

1. 화면 위쪽의 **Teachable Machine 모델 주소** 입력칸에 복사한 주소를 붙여넣습니다.
2. **감시 시작**을 누릅니다.
3. 브라우저가 마이크 권한을 물으면 **허용**을 선택합니다.
4. 소리를 내어 막대그래프가 움직이는지 확인합니다.
5. 필요하면 **경보 민감도**를 조절합니다. 기준값을 낮추면 경보가 자주, 높이면 드물게 발생합니다.

모델이 없다면 **Mock 모드**를 체크하고 감시를 시작하세요. 마이크 권한 없이 가짜 데이터로 모든 화면을 확인할 수 있습니다.

## 3. 내 컴퓨터에서 테스트하기

마이크는 보안상 HTTPS 또는 `localhost`에서만 동작합니다. `index.html`을 더블클릭하지 말고 이 폴더에서 다음 명령을 실행하세요.

```bash
python3 -m http.server 8000
```

Chrome에서 [http://localhost:8000](http://localhost:8000)을 엽니다. 수정한 내용이 보이지 않으면 `Shift`를 누른 채 새로고침하세요.

## 4. Netlify에 배포하기

1. [Netlify Drop](https://app.netlify.com/drop)에 접속합니다.
2. `index.html`, `app.js`, `style.css`가 들어 있는 이 폴더를 페이지에 끌어다 놓습니다.
3. 업로드가 끝나면 발급된 `https://…netlify.app` 주소를 엽니다.
4. 휴대폰에서도 주소를 열고 마이크 권한을 허용해 시험합니다.

별도의 빌드 명령이나 `npm install`은 필요하지 않습니다. Netlify가 HTTPS를 자동으로 적용합니다.

## 5. Gemini API 키 받기

Gemini 연결은 선택 사항입니다. 키가 없거나 요청에 실패해도 기본 상황 설명을 표시하므로 감지 기능은 계속 동작합니다.

1. [Google AI Studio](https://aistudio.google.com)에 로그인합니다.
2. API 키 만들기 메뉴에서 실습용 키를 발급합니다.
3. 앱의 **Gemini API 키** 입력칸에 붙여넣습니다.

키는 코드나 브라우저 저장소에 저장되지 않으며, 경보가 발생했을 때 클래스 이름과 확률로 상황 설명을 요청하는 데만 사용됩니다. 음성 원본은 Gemini로 보내지 않습니다. 공개 수업이나 시연이 끝나면 실습용 키를 삭제하세요.

## 파일 구성

- `index.html`: 한국어 관제 화면과 고정 버전 CDN 연결
- `style.css`: 반응형 레이아웃, 상태등, 경보 애니메이션
- `app.js`: 모델 로딩, Mock 데이터, 판정, 사이렌, 기록, Gemini 연결
- `AGENTS.md`: 프로젝트 작업 규칙
- `README.md`: 학생용 사용 안내

## 문제 해결

- 모델이 열리지 않으면 주소 끝의 `/` 유무보다 주소 자체가 정확한지 먼저 확인하세요. 앱이 `/`는 자동으로 보완합니다.
- 마이크가 켜지지 않으면 주소창의 자물쇠 아이콘에서 마이크 권한을 허용하세요.
- 사이렌을 끄려면 **사이렌 끄기**를 체크하세요. 감지를 중지하면 재생 중인 사이렌도 즉시 멈춥니다.
- 위험 소리가 계속되는 동안 사이렌과 기록은 한 번만 발생합니다. 신호가 기준값 아래로 4초간 유지된 뒤 다음 경보가 다시 활성화됩니다.
